## Presentation model

Each website project should have two deliberately separate layers:

| Layer | Visible detail |
| --- | --- |
| Public | Generic project label, approved anonymized description, role/capability context and public-safe technologies/evidence. |
| Shared-password full inventory | Full project/client name and additional approved detail, but never secrets or materially confidential content. |

Both layers require an explicit shareability decision. A password does not
authorize sharing information that Ben or the client has not approved.

## Record fields to prepare

- public label and description;
- approved full label and detail;
- client or anonymized label;
- employer/studio, dates or truthful range, industry and audience;
- Ben's role, specific contributions and collaboration context;
- approach, meaningful technologies, approved outcome evidence and assets;
- public/full shareability status, sources and approval notes.
